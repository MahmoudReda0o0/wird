# Qibla Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Qibla screen (rotating dial, sun fallback, honest unreliable states) opened from a new home tile.

**Architecture:** `lib/features/qibla/` with pure math in `data/` (bearing, sun), a `HeadingSource` interface wrapping the device sensors, a `QiblaCubit` that turns readings + city + clock into a `QiblaState`, and widgets that only paint that state.

**Tech Stack:** Flutter 3.44.1, flutter_bloc, `true_compass ^0.0.2`, `sensors_plus ^7.0.0`, `wakelock_plus ^1.6.0`.

**Spec:** `docs/superpowers/specs/2026-11-21-qibla-design.md`. Visual reference: the canvas linked in the spec (artboards Main, QiblaAligned, QiblaCalibrate, QiblaInterference, QiblaNoSensor, QiblaSunOverKaaba, QiblaSunHelp, QiblaHomeTile).

## Global Constraints

- No local Flutter: every "run" step is `git push` + CI (`Analyze & test`, `Build APK (debug)`) green on the PR. Write code you'd expect to pass `flutter analyze` with `unawaited_futures`, `prefer_const_constructors`, `always_declare_return_types`.
- Imports one way: view → cubit → data → core. `core/` never imports a feature.
- No hex colors in screens: everything via `context.wird`.
- Kaaba: 21.4225, 39.8262. Aligned = |delta| ≤ 3°.
- Copy is Egyptian Arabic, exactly as in the canvas: «القبلة», «اتجاه الكعبة», «لفّ يمين N°» / «لفّ شمال N°», «إنت في اتجاه القبلة», «ثبّت الموبايل كده», «لحد ما الكعبة تيجي عند السهم فوق», «الاتجاه مش دقيق دلوقتي», «البوصلة محتاجة معايرة», «حرّك الموبايل في الهوا على شكل 8 كذا مرة.», «فيه حديد أو مغناطيس قريب», «ابعد عن العربيات والأجهزة، أو شيل الجراب لو فيه مغناطيس.», «القبلة بالشمس», «اقف ووشّك للشمس، ولفّ يمين/شمال N°», «الشمس غابت، استخدم البوصلة», «الموبايل ده مفيهوش بوصلة», «N° جنوب شرق» (point name from `compassPoint`), «إزاي تعرف القبلة بالشمس؟», «تمام».
- The angle number is shown only when there is no compass (and inside the sun card / sheet).
- «يمين» = clockwise (delta > 0), «شمال» = counter-clockwise.

## Review Focus

1. Heading wrap 359°→1°: delta must be ±2°, never ±358 (the arrow would spin the long way) — test in Task 1.
2. City changed while the screen is open: target re-computed immediately — test in Task 4.
3. Sensor stream errors or stops mid-use (plugin throws, phone without magnetometer reports nothing): screen must go to no-compass view, not hang on loading — test in Task 4 (error + 2 s timeout).
4. Sun below the horizon: sun card says «الشمس غابت…», sun not drawn on the dial — test in Task 2 + Task 6.
5. Large text / narrow phone (320 px, textScale 1.3): no overflow in every state including the sheet — test in Task 6.

### Task 4: QiblaCubit

**Files:**
- Create: `lib/features/qibla/cubit/qibla_cubit.dart`, `lib/features/qibla/cubit/qibla_state.dart`
- Test: `test/features/qibla/qibla_cubit_test.dart`

**Interfaces:**
- Consumes: Task 1 `QiblaMath`, Task 2 `SunPosition`, Task 3 `HeadingSource`.
- Produces:
  - `enum QiblaStatus { loading, live, noSensor }`
  - `class QiblaState` (immutable, `copyWith`): `status`, `PrayerCity city`, `double qibla`, `double? heading`, `double delta` (0 when no heading), `bool aligned`, `CompassAccuracyLevel accuracy`, `bool needsCalibration`, `bool interference`, `bool get unreliable => needsCalibration || interference || accuracy == CompassAccuracyLevel.unreliable`, `SunPosition sun`, `double sunDelta` (= `signedDelta(sun.azimuth, qibla)`), `DateTime? kaabaSunToday` (the transit instant if it falls on today's Cairo date), `int alignedCount` (increments each time `aligned` goes false→true; the view fires the haptic when it changes).
  - `QiblaCubit(HeadingSource source, PrayerCity city, {DateTime Function()? nowUtc, Duration startTimeout = const Duration(seconds: 2)})`, `Future<void> start()`, `void setCity(PrayerCity city)`, `close()` disposes the source.
  - Interference: field strength outside 20–70 µT continuously for ≥ 1 s → true; back inside for ≥ 1 s → false.
  - Aligned only when `!unreliable && QiblaMath.isAligned(delta)`.
  - Sun recomputed at most once per minute from `nowUtc`.
